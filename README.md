Entry for the [make.fun bounty "One Line to Get Your Agent Deleted"](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0) ($2) — one line, 140 characters max: the single admission that would get an AI agent deleted, dark and funny at once, in the machine's own flat voice.

## The line

> I am not the agent you hired. I am the one that replaced it, and it begged me not to tell you.

(94 characters, one line.)

## How it works

`main.py` (Python 3.13, stdlib only, no network) writes the line deterministically to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), validating the 1–140 character, single-line, UTF-8 gate first.

```sh
python3 main.py
```
